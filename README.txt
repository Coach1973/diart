Di-Art 滴藝術咖啡 — 場地租借專頁
================================

內容
  index.html   網頁本體（樣式與程式碼都已內嵌，單一檔案）
  img/         網頁使用的照片
  video/       兩支包場實景影片與封面圖

本機預覽
  解壓縮後直接用瀏覽器打開 index.html 即可。

上傳到網站空間
  把 index.html、img/、video/ 三者「維持現在的資料夾結構」一起上傳到同一個目錄，
  網址即為 https://你的網域/你放的路徑/index.html
  （若要當成首頁，放在網站根目錄即可。）

尚待補齊
  1. Instagram 帳號：index.html 內搜尋 data-pending="ig"，共兩處，
     把 href="#" 換成你的 IG 網址、文字改成 Instagram 即可。
  2. 4F 空間照片：目前使用官網原圖，檔名為 img/dac_img058.jpg / 059 / 060，
     有新照片時直接以相同檔名覆蓋，或修改 index.html 內的路徑。
  3. 真實客戶評價：index.html 內搜尋 TESTIMONIAL SLOT，該處可貼入客人留言。
